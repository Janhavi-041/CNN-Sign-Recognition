# CNN Based Sign Recognition Using Python

## Project Description
A Python project using CNN to recognize sign language gestures accurately.

## Files Included
- signcnn.py → model training
- main_app.py → application
- asl_model.keras → trained model

## Dataset
Dataset used from Kaggle:
(https://www.kaggle.com/datasets/ayuraj/asl-dataset?resource=download#)

Note:
Dataset (~2GB) is not uploaded due to size limitations.

## How to Run
1. Run signcnn.py
2. Run main_app.py
