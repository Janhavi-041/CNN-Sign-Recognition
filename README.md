# CNN Based Sign Recognition Using Python

## Project Description
A Python project using CNN to recognize sign language gestures.
It detects hand gestures and predicts corresponding alphabets in real-time.

---

## 🚀 Features
- Real-time sign language recognition
- CNN-based image classification model
- Trained on ASL dataset
- GUI application using Python
- Model saved for direct prediction

---

## 📂 Project Files
- `signcnn.py` → CNN model training and development
- `main_app.py` → Application to test predictions
- `asl_model.keras` → Trained deep learning model

---

## 📊 Dataset
The dataset used for training is from Kaggle:

👉 (https://www.kaggle.com/datasets/ayuraj/asl-dataset?resource=download#)

> Note: The dataset (~2GB) is not included in this repository due to size limitations.

---

## 🧠 Model Details
- Model Type: Convolutional Neural Network (CNN)
- Framework: TensorFlow / Keras
- Input: Hand gesture images
- Output: Predicted ASL alphabet class

---

## 🛠 Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
